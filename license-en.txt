PART 1. PRIVACY POLICY
================================================================

1. The short version
The program runs on your computer. It has no accounts, ads or analytics. The author does not receive any of your data and does not collect it.

2. What data the program processes on your computer
- Playback information from Windows: track title, artist, cover art, player state and the name of the player app. Needed to show and control music playback.
- The name of the active window (process) and time spent in apps during the day. Needed for the Home card, "Do Not Disturb" mode and the "Day summary" tab. The program does not read window contents, keystrokes or files.
- Daily statistics: number of screenshots taken, number of tracks listened to, time spent in "Do Not Disturb" mode, number of completed timers.
- Your notes, reminders, favorite tracks, list of pinned apps, appearance settings, and the background image and notification sound you chose (copies of these files).
- Battery level, current time, and CPU/RAM load (Home card block). These values are only displayed and are never saved anywhere.

3. Where this is stored
Everything listed above is saved only in local program files on your computer (in the app data folder or next to the program) and is never sent anywhere. The work log (media.log) is also stored locally and contains technical entries, such as track names.

4. Internet access
- Weather (optional): by default the weather block is off, and the program does not access the internet for weather. If you enable the "Weather" block in the "Design" tab, the program requests an approximate location from your IP address via the ipwho.is service, then a forecast from the Open-Meteo service (open-meteo.com, data under the CC BY 4.0 license) using those coordinates. These services see your IP address. This data is not passed to the author of the program. These services' own policies apply independently of this document.
- Links: clicking "corzyyy" opens https://t.me/corzyyy. Clicking a favorite track may open a search for that track in Yandex Music (in your browser) or in Spotify. Such links open only when you click them.
- There is no other exchange of data with the internet.

5. Changes to the system
- "Do Not Disturb" mode temporarily changes Windows notification settings for the current user (in the registry) while active, and restores them when the mode is turned off. If the program crashes, the settings are restored on the next launch.
- Autostart adds the program to the current user's startup list. It can be turned off from the "Design" tab or the tray icon's menu.
- Volume, files and settings of other programs are not changed.

6. How to delete your data
Remove the program via "Settings → Apps" and then delete its data folder. You can copy any files you need (notes, settings) beforehand. Data is not stored anywhere except your own computer.

7. Changes to this policy
New versions of the program may update this document. The current version is shown during installation.
