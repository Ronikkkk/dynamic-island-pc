Island for Windows

Политика конфиденциальности

Действует с 1 ноября 2026 года · относится к приложению Island for Windows для Windows 10/11

Коротко: Island for Windows — программа для одного компьютера. Она не отправляет данные на сервер, не показывает рекламу и не требует регистрации. Всё, что программа читает, остаётся на вашем компьютере и используется только для работы самой программы.

Что читает

Данные, которые использует программа

Код компьютера. Программа считает его на устройстве из системного идентификатора Windows и использует только для проверки лицензии. Код не передаётся автоматически никуда — вы сами решаете, показать ли его при покупке.

Текущий трек. Название, исполнитель и обложка альбома — из системной медиа-сессии Windows (это те же данные, что видны в центре уведомлений). Используются только для показа в «острове».

Активное окно. Название запущенной программы — чтобы автоматически скрывать остров поверх игр и полноэкранных окон, а также чтобы считать время в приложениях для сводки дня.

Где хранится

Хранение данных

Все данные хранятся локально, в папке программы на вашем компьютере, и не синхронизируются ни с каким сервером. Удаление программы удаляет и эти данные.

Программа не использует аналитику, трекеры и рекламные идентификаторы.

Покупка Pro

Платная версия

Чтобы оформить Pro, вы по собственному желанию открываете отдельный чат с Telegram-ботом разработчика и пишете ему код компьютера. Эта переписка идёт через Telegram и подчиняется политике конфиденциальности Telegram, а не этой программы.

Дети

Возрастные ограничения

Island for Windows не предназначена специально для детей и не собирает данные о них осознанно.

Изменения

Обновления политики

Если условия изменятся, новая версия появится на этой же странице с обновлённой датой наверху.
