Island for Windows

Privacy Policy

Effective November 1, 2026 · applies to the Island for Windows app for Windows 10/11

In short: Island for Windows is a single-computer program. It does not send data to any server, does not show ads, and does not require registration. Everything the program reads stays on your computer and is used only to run the program itself.

What it reads

Data the program uses

Computer code. The program calculates it on your device from a Windows system identifier, and uses it only to verify the license. The code is never sent anywhere automatically — you decide yourself whether to share it when purchasing.

Current track. Title, artist and album art — from the Windows system media session (the same data shown in the notification center). Used only to display it in the island.

Active window. The name of the running program — to automatically hide the island over games and full-screen windows, and to count time spent in apps for the day summary.

Where it's stored

Data storage

All data is stored locally, in the program's folder on your computer, and is not synced with any server. Removing the program also removes this data.

The program does not use analytics, trackers or advertising identifiers.

Buying Pro

Paid version

To get Pro, you voluntarily open a separate chat with the developer's Telegram bot and send it your computer code. That conversation happens through Telegram and is governed by Telegram's own privacy policy, not this program's.

Children

Age restrictions

Island for Windows is not specifically directed at children and does not knowingly collect data about them.

Changes

Policy updates

If the terms change, a new version will appear on this same page with an updated date at the top.
